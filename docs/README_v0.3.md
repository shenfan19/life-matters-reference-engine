# Life Matters: 医学与社会学仿真建模框架

## 项目概述

**Life Matters** 是一个创新的仿真建模框架，专为医疗和社会学研究设计，旨在通过模块化、数据驱动的方式，为科研人员提供研究复现工具，同时为非专业用户提供直观、互动的仿真体验。平台采用类游戏的 Modding 机制，允许用户通过简单配置文件（如 YAML）组合和运行复杂模型，轻松实现疾病传播、治疗效果评估、人口迁移等场景的仿真。

无论是学术研究人员希望验证理论模型，还是教育工作者希望向学生展示复杂系统，**Life Matters** 都能提供灵活、友好的解决方案。当前版本（v1.0）已实现稳定的用户界面和核心功能，支持模型加载、仿真展示和多模块管理，为医疗和社会学领域的探索奠定了坚实基础。

## 核心功能

### 1. 模块化模型管理
- **单模型仿真**：加载单一模型（如消化系统、糖尿病模型），研究个体行为和参数变化。
- **多模型整合**：支持多个模型协同运行，分析模型间的交互影响。
- **数据驱动**：通过 YAML 配置文件定义模型参数、公式和触发条件，无需编程即可定制仿真。

### 2. 研究复现与验证
- **模型生成**：从研究论文中提取数据，生成统一格式的仿真模块（例如，医疗、饮食、压力等）。
- **模型验证**：校验模型参数，确保仿真结果符合科学结论和现实数据。
- **优化研究**：基于期望指标（如健康结果、社会效应），优化多模型系统的表现。

### 3. 互动体验
- **类游戏操作**：用户可像玩游戏（如魂斗罗或俄罗斯方块）一样操控仿真变量，例如调整输入（如“攻击”或“远离”），观察状态变化。
- **暂停与控制**：支持暂停仿真，通过图形界面（GUI）或命令行调整参数。
- **直观界面**：提供友好的 Web 界面，包含模型选择、标签页导航（单模型生成、验证、多模型仿真、优化）和主题切换（明亮/黑暗模式）。

### 4. 跨领域应用
- **医疗研究**：模拟疾病传播、评估治疗效果、优化医疗资源分配。
- **社会学研究**：分析人口迁移、社会网络演化、政策影响。
- **教育培训**：通过交互式仿真，教授复杂系统概念，培训政策制定者。

## 为什么选择 Life Matters？

- **科研与科普双定位**：满足研究人员验证模型的需求，同时让非技术用户轻松上手。
- **模块化设计**：采用类游戏 Modding 机制，用户可自由组合模型，扩展新功能。
- **零编程门槛**：通过配置文件（如 YAML）驱动仿真，无需编码即可参与设计。
- **灵活扩展**：支持动态加载新模型，适用于医疗、社会学等多领域。

## 使用案例

- **传染病传播**：模拟病毒传播速度，评估隔离政策效果。
- **医疗资源优化**：分析医院床位分配，预测治疗需求。
- **人口迁移研究**：探索城市化对社会网络的影响。
- **教育演示**：通过互动仿真，向学生展示疾病动力学或社会系统演化。

## 快速开始

### 1. 获取项目
```bash
git clone https://github.com/yourproject/life-matters.git
```

### 2. 安装依赖
确保已安装 Python 3.13 和 Flet：
```bash
pip install flet pyyaml
```

### 3. 运行示例
```bash
python interface_expert.py
```
- 浏览器访问 `http://localhost:8550`。
- 选择模型（如 `DigestiveSystemAdvanced`），切换标签页查看仿真结果。

### 4. 自定义仿真
- 修改 `mods` 目录中的 YAML 文件（如 `enhanced_yaml_config.yaml`）。
- 在界面中选择模型，运行仿真或调整参数。
