## MOD 用户协议

```yaml

1. 免责声明

    不代表LM-Game官方立场
    官方不对MOD内容负责
    如有违法/侵权内容，请举报"

2. MOD创作者责任
   "上传MOD表示你确认:
    - 内容不违反当地法律
    - 不侵犯他人版权
    - 愿意承担法律责任"

3. 举报机制
   "如发现不当内容:
    - 点击[举报]按钮

   "我们保留删除任何MOD的权利
    无需提前通知"
```

## MOD 审核策略

```yaml

  ✓ 用户自由上传
  ✓ 不预审内容
  → 保持平台免责

但响应举报（法律要求）:
  ✓ 24小时内审核举报
  ✓ 删除明显违法内容:
```
