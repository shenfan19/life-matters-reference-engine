# LM-Game 需求文档

## 核心定位

基于 LM-sim 动力学引擎的卡牌叙事游戏，以历史人物的多条人生轨道为载体，让玩家在反复重生中理解选择的代价。

**交互范式**：卡牌式叙事（Card-Based Narrative）

## 游戏机制

### 三变量制衡系统

- **生命值（Health）**：核心血条，判定胜负的唯一指标，代表生理极限
- **金钱（Money）**：卡牌费用，出牌消耗，通过"劳作卡"获取，通过"生活卡"消耗
- **地位（Status）**：卡池等级，决定可抽卡池；低等级只有"苦力牌"，高等级解锁"资源牌"

### 三层运行模式

| 模式 | 核心体验 | 对应 LM 架构 |
|------|---------|------------|
| **基础线**（一周目） | 历史真实压迫感，玩家 = 渺小个体，目标是"理解"而非"赢" | 单动力学主线激活 |
| **IF线**（二三周目） | 带着上一周目解锁的特质，探索历史人物未走的路 | 不同动力学维度激活 |
| **全维度隐藏线** | 集齐所有特质后解锁，所有动力学同时激活，最高难度 | 全部动力学并行 |

### Rogue 扩展模式（与上述正交）

引入反事实道具（赛博义体、提前发明的青霉素、未来知识）打破历史枷锁，提供游戏粘滞力。

## 数据映射设计

将 LM-Research 的 YAML 仿真结论直接映射为游戏机制：

| 人生维度 | 激活的动力学 | 对应模型 |
|---------|------------|---------|
| 科学路线 | `radiation_exposure` + `research_momentum` | 辐射积累 × 研究复利 |
| 爱情路线 | `grief_recovery` + `intimacy_dynamics` | 失去 × 韧性 |
| 国家路线 | `war_stress` + `resource_sacrifice` | 战争压力 × 资源牺牲 |
| 社会路线 | `social_pressure` + `resilience` | 压力 × 反弹 |

卡牌游戏的计算单元约束：
- 离散、整数、回合制
- 玩家可形成因果直觉
- 新状态 = f(旧状态, 卡牌效果)，f 只支持加减乘除 + 条件分支

## 设计原则

1. **去积分化**：不用抽象积分，用直观的三变量
2. **历史教育框架**：道德重量、伤痛再现，框架是"教育"而非"批判"
3. **无上帝视角**：玩家视角始终是历史压力下的渺小个体
4. **年龄分级 + 触发警告**
5. **捐赠机制**
6. **战场张力框架**：凡含"战场"场景（战役、前线医疗、战时科学）的故事，必须同时包含以下两个 Game-native 变量，构建个人生命与集体战局之间的张力：
   - `battle_progress`（战局进度，0–100）：代表集体目标的推进程度，完全独立于角色个人存活；
   - `danger_accumulation`（危险累积，0–100）：每回合自动累积，驱动角色暴露风险递增（P2 模式）。

   **核心张力**：在战场上多留一回合，`danger_accumulation` 上升，但也有更多时机推进 `battle_progress`；提前牺牲可换取 `battle_progress` 的跃进。两种策略均为合法选择，游戏不作道德裁判。

   **贡献路径分层**（同一框架，不同语义）：
   - 战斗角色（士兵）：通过进攻行动直接推进 `battle_progress`
   - 医疗角色（南丁格尔、希波克拉底）：通过降低伤亡率/病死率间接推进
   - 后勤/科学角色（居里夫人国家线）：通过资源与知识贡献推进

   **架构归属**：`battle_progress` 与 `danger_accumulation` 均为 story-native 变量，不经 Sim 建模，不需要 Converter 处理（见 `game_impl.md § 变量溯源标注`）。

## 与 LM-Research 的关系

- **共享**：仿真引擎（同一套动力学）、Scenario 格式（YAML）、数据源（文献）
- **独立**：UI、用户群（专业 vs 大众）、推广策略
- Game 作为 Research 的公众可视化层

## MOD 系统需求

**核心定位**：官方搭框架，社区填内容；官方不干涉 MOD 内容立场，以科研框架为边界。

### 场景 MOD

- 用户可创作新的历史场景（新的 `models/stories/{category}/{id}/`）
- 场景须符合 `game_story.yaml` 格式规范（见 `game_impl.md`）
- 支持自定义角色、卡牌、初始参数

### 内容分级

- MOD 须标注内容分级（年龄限制）和触发警告（暴力/死亡/歧视主题）
- 官方场景同样须遵守此规范

### 社区治理

- 用户可上传 MOD，平台不预审
- 举报机制：24小时内响应明显违法内容
- MOD 创作者须承担其内容的法律责任

### 角色邀请机制

- 开放用户写信邀请设计新官方角色（非开放全员提交）
- 设计摩擦成本：筛出真正有热情的人，每封信都是潜在社群故事

### 安全边界

- 以项目为重，以医学为重，官方不主动碰敏感话题
- 社会学 MOD 开放：用户可添加不同民族、政治观点的内容
- LM 官方：不干涉、不支持、不宣传，以科研框架为本
- 防火墙原则：保持"框架是教育而非批判，数据是历史而非政治"，避免成为代理战场
