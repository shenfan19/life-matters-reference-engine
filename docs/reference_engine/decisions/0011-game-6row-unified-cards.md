# 0011 — Game 6行对称布局 + 统一卡牌尺寸 + 对方手牌机制

**状态**：✅ 已实施  
**日期**：2026-04-04

## 背景

0010 的布局将环境区与玩家区分为两大区域，但缺少对称感，且卡牌尺寸在不同位置不一致（手牌比场地牌高出 20px）。用户希望进一步对齐炉石传说的对战视觉语言。

## 决策

### 1. 6行纵向布局

从上至下完整对称：

| 行 | 高度 | 内容 |
|----|------|------|
| 1 | `ROW_HP = 50px` | 对方目标 HP 条（环境/剧情目标）|
| 2 | `ROW_CARD = 142px` | **对方手牌**（面朝下，下回合翻开）|
| 3 | `ROW_CARD = 142px` | **对方场地**（本回合触发的环境卡）|
| 4 | `ROW_CARD = 142px` | **我方场地**（驻场卡 + 本轮暂存卡）|
| 5 | `ROW_CARD = 142px` | **我方手牌**（可出牌）|
| 6 | `ROW_CTRL = 36px` | 操作条（AP 满/结束回合）|
| 7 | `ROW_HP = 50px` | 我方状态 HP 条 |

行 1/7 仅含 HP 条，无卡牌。行 2-5 是对战核心区域。

### 2. 统一卡牌尺寸

定义全局常量：
```typescript
const CARD_W = 100;  // px
const CARD_H = 106;  // px
const ROW_CARD = 142; // = CARD_H + 上下 padding 各 18px（含角标出血 8px）
```

所有位置（手牌、场地卡、驻场卡、环境卡、牌堆图形）全部使用相同的 `CARD_W × CARD_H`。牌堆视觉与卡牌等大，使右侧列视觉一致。

以前场地卡使用 `CARD_H - 20` 的缩小版本，现在统一为 `CARD_H`。

### 3. 统一 `GameCard` 渲染组件

之前 `EnvCardView` 和玩家手牌卡片是两个独立组件，存在尺寸和样式差异。重构为单一 `GameCard` 组件，通过 props 区分：

- `cost` prop：有则显示左上角费用角标（仅我方卡）
- `duration` prop：持续回合数，显示右上角角标（所有卡），`0 → 即`，`-1 → ∞`，`N → N`
- `remaining` prop：驻场卡剩余回合（优先于 duration 显示右上角）
- `triggered` / `showMissed` prop：环境卡专用

角标位置：
- **左上角 = 费用（Cost）**：仅我方手牌卡
- **右上角 = 倒计时（Duration/Remaining）**：所有卡均显示

### 4. 对方手牌机制（envHand）

新增 `envHand: EnvCard[]` 状态，实现一回合预告：

```
Turn N 结束:
  curEnvHand (上轮抽的牌) → 翻开 → envRevealed (对方场地)
  evtDeck 抽 N 张 → newEnvHand (本轮抽的牌, 面朝下)

Turn N+1:
  玩家看到对方手牌区 N 张面朝下的卡
  可以知道"对方还有几张牌"，但不知道是什么
  Turn N+1 结束时翻开
```

游戏开局时预先抽一轮牌到 `envHand`，让第 1 回合开始时对方手牌非空，不会出现空白行。

### 5. 右列牌堆精确对齐

右侧牌堆列使用与主列相同的行高常量，实现精确对齐：

```
右列高度分区:
  ROW_HP      ← 行1占位（空）
  ROW_CARD    ← 行2: 事件牌组（对应对方手牌）
  ROW_CARD    ← 行3: 事件弃牌（对应对方场地）
  ROW_CARD    ← 行4: 我方弃牌（对应我方场地）
  ROW_CARD    ← 行5: 我方牌组（对应我方手牌）
  flex: 1     ← 行6-7占位（空）
```

牌堆弃牌在中间，与"打出的牌从这里经过"的直觉一致。

### 6. 左侧状态栏（游戏日志）

将游戏日志移至左侧固定面板（168px），内含：
- 大号回合计数器 + AP 指示点
- 完整可滚动的事件日志（所有历史条目）

操作控件（结束回合按钮）移至行 6（控制条），AP/回合 信息在左侧面板。

## 后果

- ✅ 上下对称，双方信息量均衡，战场感强
- ✅ 卡牌尺寸统一，手牌和场地无视觉落差
- ✅ 对方手牌机制增加策略信息（知道对方"还有几张"）
- ✅ 牌堆精确对齐行，视觉逻辑清晰
- ⚠️ 总高度约 730-760px（依屏幕），小于 768px 高度的设备会出现竖向滚动条
- ⚠️ 对方手牌面朝下（只见数量不见内容），后续可在结算后翻面动画增强表现力
