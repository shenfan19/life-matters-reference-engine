# 0032 — sim_gui 默认字号调整为 14px

**状态**：✅ 已实施  
**日期**：2026-04-16

## 背景

sim_gui 的 Ant Design 主题 `token.fontSize` 基准一直是 16px，与 `FontSizer` 三档选项 `[14, 16, 18]` 的中间档一致。

但在实际使用中，16px 对工具型/学术型软件显得偏大——仿真/优化按钮行、左侧导航项的字号均明显大于同类参考软件（MATLAB、R Studio、SPSS 等）。这些软件普遍以 12–14px 为正文基准，将更多信息密度留给数据和图表。

## 决策

将 `sim_gui` 的 `FontSizer` 档位和默认值整体下移一档：

| | 改前 | 改后 |
|---|---|---|
| 可选档位 | `[14, 16, 18]` | `[12, 14, 16]` |
| 默认值（无缓存时）| `16` | `14` |

`game` 的字号系统不受影响——game 属于娱乐/叙事场景，16px 可读性优先完全合理。

## 理由

- 学术工具软件约定俗成使用更小的基准字号，用户不需要被强迫通过选择器降档
- 14px 是 Web 工具软件的常见基准（如 VS Code 默认编辑器字号为 14px）
- `FontSizer` 仍保留三档供用户覆盖，灵活性不变
- 已有 localStorage 缓存的用户不受影响，只有新用户或清除缓存后才看到新默认值

## 后果

- ✅ 初次打开的用户获得更贴合学术工具期望的视觉密度
- ✅ 档位范围 `[12, 14, 16]` 覆盖从紧凑到舒适的全部常用需求
- ⚠️ 已有用户 localStorage 中存的是 `16`，仍会以 16px 打开，需手动切换（刻意保留，避免破坏已有偏好）
- ⚠️ `fontSizeSM = max(11, base - 3)`，在 base=12 时 SM 为 11px，接近可读下限，日后若再下移需重新评估
