# ADR 0045 — 概率仿真与 Monte Carlo 架构：parameter 分布表达式、多 run 引擎、前端渲染
**日期**：2026-04-30（决策时间 2026-04-24，此时补录）
**状态**：已实施

---

## 背景

模型中存在个体差异（如 `cognitive_efficiency`、`plague_susceptibility`、`insulin_sensitivity`），需要一种机制表达参数的不确定性，并让仿真在多条轨迹间可见这种不确定性。

---

## 决策

### 决策一：`parameter` 变量支持分布表达式

`type: parameter` 的 `value` 字段可写分布字符串：

| 语法 | 含义 |
|------|------|
| `normal(μ, σ)` | 正态分布 |
| `uniform(a, b)` | 均匀分布 |
| `lognormal(μ, σ)` | 对数正态分布 |

- **确定性模式**（MC=1）：取均值，等价于 `value: μ`
- **MC 模式**（MC>1）：每条 run 用独立 `np.random.default_rng(seed)` 采样一次，整条 run 使用该采样值

```yaml
insulin_sensitivity:
  value: "normal(1.0, 0.25)"
  type: parameter
  bounds: [0.2, 2.5]
```

### 决策二：Sim 模式 —— 默认 N=1，可选 Monte Carlo

| 参数 | 默认 | 范围 |
|------|------|------|
| `sim_runs` | 1 | 1–100 |

- N=1：单条轨迹，快速预览
- N>1：N 条独立采样轨迹，前端展示不确定性范围

### 决策三：前端图表渲染

- N=1：单条实线
- N>1：N 条半透明细线（opacity ≈ 0.25）+ 一条均值粗线（opacity = 1.0）

### 决策四：Opt 模式 —— 方案 B（多条期望迭代）

优化器每次评估一组参数时运行 N_inner 条仿真，取**均值**作为目标函数值，避免单条固定种子的泛化性问题。

| 参数 | 默认 | 范围 |
|------|------|------|
| `opt_inner_runs` | 5 | 1–20 |
| `opt_verify_runs` | 20 | 5–50 |
| `opt_aggregation` | `mean` | `mean/min/median` |

后续演进方案 C：Phase 1 快速探索（N=1）→ Phase 2 精细收敛（N=5–10）→ 最终验证（N=20）。

### 决策五：随机种子管理

- Session 启动时预生成 `[seed_1, ..., seed_N]`，保证同一 session 内 N 条曲线可复现
- 不同 session 之间种子真随机
- `session_seed` 从 start API 返回，写入前端 state

### 决策六：MC 分叉可见性原则

MC 分叉**只出现在被 MC 参数直接或间接影响的变量**。建模时需确保：
- 有 `normal(...)` 的 parameter 必须出现在至少一个公式的表达式中
- 观察分叉时应选择该 parameter 参与计算的 output 变量（而非 schedule 驱动的确定性变量）
