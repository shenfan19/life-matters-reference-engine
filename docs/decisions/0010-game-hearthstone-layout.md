# 0010 — Game 界面 Hearthstone 式布局重构

**状态**：✅ 已实施  
**日期**：2026-04-04

## 背景

CardGame 的初版布局将所有元素堆叠在一个垂直滚动面板内：左侧 HP 条、中央环境牌组、下方手牌。随着卡牌机制（驻场、弃牌堆、双方牌堆）逐步加入，界面的信息密度和空间逻辑变得混乱，缺乏「打牌」的感觉。

## 决策

以炉石传说（Hearthstone）为参考原型，重构整体布局：

### 1. 整体结构：主列 + 右侧牌堆列

```
[ Top bar ]
[ 主列 (flex: 1) | 右列 (CARD_W + 20px) ]
```

右列专门放置双方牌堆和弃牌堆，固定宽度 = 卡牌宽度 + 内边距，使牌堆与卡牌等宽，视觉一致。

### 2. 主列纵向分区（上至下）

| 区域 | 高度 | 内容 |
|------|------|------|
| 对方区 | flex: 2 | 目标血条在 **顶部**；剩余空间留空备用 |
| 环境战场行 | 110px 固定 | 本回合触发的环境卡（对方"随从行"）|
| 玩家战场行 | 110px 固定 | 驻场卡 + 暂存卡（玩家"随从行"）|
| 玩家区 | flex: 3 | 手牌（上）→ 操作栏（中）→ 状态血条（下）|
| 日志条 | 62px 固定 | 最近 6 条事件 |

两个战场行相邻，形成炉石风格的「双方战线」。

### 3. 血条位置调整

- **目标血条**（对方/环境目标）：移至对方区**顶部**，紧贴区域上边缘
- **状态血条**（玩家自身状态）：移至玩家区**底部**，紧贴日志条上方

原因：符合视角直觉——对方信息在上，己方信息在下，且手牌操作区居中，优先级最高。

### 4. 右列牌堆排列（上至下）

```
事件牌组（牌背朝上）
事件弃牌
────── 分隔线（对应两行战场的中线）──────
我方弃牌
我方牌组（牌背朝上）
```

- `justify-content: space-between` 使四个牌堆均匀分布
- 牌堆尺寸 = `CARD_W × CARD_H`（与手牌等大）
- 玩家从右侧抽牌，与右列位置呼应

### 5. 环境卡"无手牌"设计

环境方不持有手牌。每回合结束时，从事件牌组直接翻出若干张牌，触发后显示在环境战场行（`envRevealed`），相当于"直接从牌堆出牌到战场"。常驻卡（`always_active`）同样合并显示在此行，不再单独设"常驻"区。

### 6. 卡牌角标调换

- **左上角** = 费用（AP Cost），与传统卡牌游戏一致（炉石、昆特牌均费用在左）
- **右上角** = 持续回合数（Duration），辅助信息靠右

### 7. 牌堆大小 = 卡牌大小

`DeckPile` 组件使用常量 `CARD_W = 110, CARD_H = 130`，与手牌卡片保持一致，堆叠偏移用 `position: absolute + offset` 实现厚度感。

## 后果

- ✅ 双方战场行明确，玩家能直观感受到"我的场地"和"对方的场地"
- ✅ 四个牌堆集中在右侧，操作动线清晰（从右抽牌）
- ✅ 血条位置符合视角直觉，手牌区处于视觉中心
- ⚠️ 对方区的空白区域（目标血条以下）目前留空，后续可用于展示对方英雄/场景信息
- ⚠️ 右列使用 `justify-content: space-between`，在极小屏幕（< 700px 高）可能导致牌堆重叠，届时可改为 `overflowY: auto`
