# 0012 — Game 中性主题 + 双应用色彩 Token 统一

**状态**：✅ 已实施  
**日期**：2026-04-05

## 背景

Game 最初使用深绿色调底色（`#0d1a10`、`#1e3824`），与 sim_gui 的中性黑白风格差异明显。用户要求两个应用保持视觉统一：黑白为主色调，深绿/浅绿仅作主题色用于关键部位勾勒。

此外，第一轮颜色修改使用了近似值（如暗色 textSec `0.72`、亮色 text `#111111`），而非严格对齐 sim_gui 的实际 C token 值。

## 决策

### 1. 底色从深绿改为中性黑白

| 模式 | 旧底色 | 新底色 |
|------|--------|--------|
| 暗色 | `#0d1a10`（深绿） | `#111111`（纯黑） |
| 亮色 | `#1a2e1a`（绿灰） | `#f5f5f5`（浅灰） |

绿色仅保留于：primary 色（`#52c41a` / `#007A33`）、HP 进度条、卡牌费用角标、部分高亮边框。

### 2. 严格对齐 sim_gui C token

Game 的 `getC()` 与 sim_gui 的 `C` 对象使用完全相同的数值：

```typescript
// 暗色模式
bg:       '#111111'
panel:    '#1a1a1a'
border:   '#2a2a2a'
text:     'rgba(255,255,255,0.92)'
textSec:  'rgba(255,255,255,0.75)'   // 非 0.72
textMute: 'rgba(255,255,255,0.52)'   // 非 0.45

// 亮色模式
bg:       '#f5f5f5'
panel:    '#ffffff'
border:   '#e0e0e0'
text:     '#1a2e22'                  // 非 '#111111'
textSec:  '#6b7280'
textMute: 'rgba(0,0,0,0.55)'
```

### 3. Ant Design ConfigProvider token 同步

两个应用的 `colorBgBase`、`colorBgContainer`、`colorBorder` 均动态取自上述 token，不再硬编码。

## 后果

- ✅ 两个应用打开后视觉无缝衔接，色调一致
- ✅ 绿色作为主题色更突出，不与底色混淆
- ✅ token 单一来源，后续修改只需改 `getC()` 一处
- ⚠️ 深绿底色的"生命感"减弱，改由 HP 条和主题色承担视觉表达
