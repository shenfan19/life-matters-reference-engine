# Generator 模块说明 (Model Generation)

## 功能说明
本模块将医学论文中的研究结论数据，转化为可以用来积分迭代的动力学模型及参数。包括且不限于：

- 吸烟导致肺癌发病率增加 n%
- 压力导致发病率增加 n%
- 药物对病情的疗效
- 药物的副作用概率

## 医学论文结论的常见形式与可转化性

医学 paper 与研究的结论通常有以下几种形式，红绿标注转化可行性：

| 结论形式 | 示例 | 可转化为动力学模型？ |
|---|---|---|
| 相对风险/概率增减 | 吸烟使肺癌发病率提高35% | ✅ 直接转化为参数乘数 |
| 剂量-效应关系 | 每日摄入 >25g 酒精，肝病风险增加1.9倍 | ✅ 转化为 `formula` 的条件动力学 |
| 生存分析/KM曲线 | 5年生存率从 60% 降至 40% | ✅ 转化为衰减率参数 |
| 药物疗效（RCT 结果） | 药物 A 使血压降低 10 mmHg，持续 6 周 | ✅ 转化为干预型 `formulas` |
| 危险因素交互 | 吸烟 + 饮酒协同增加风险 | ⚠️ 需要多模型组合（`imports`） |
| 人群统计学结论 | 某地区 65 岁以上糖尿病患病率 20% | ⚠️ 只能作为初始值，非动力学 |
| 机制性描述（叙述性） | "T 细胞参与免疫调节过程" | ❌ 过于定性，需人工建模 |

## 生成方式

有以下几种生成策略，可组合使用：

1. **手动选择模型类型 + 填入数据**（当前 MVP 方式）
   - 用户在 GUI 中选择结论类别（如"相对风险增减"），输入数值和变量名，系统自动填充 YAML 模板。
   - 适合：有充分医学背景的研究者，追求精确控制。

2. **填写常见结论关键词，自动生成 mod**（未来规划）
   - 用户输入关键词或粘贴论文摘要，LLM（大语言模型）提取参数，自动填充 Generator 表单。
   - 适合：快速原型开发、非医学背景设计者。

3. **社区模型库查找 + 参数覆写（Patch）**（当前已支持）
   - 从 `mods/core/` 已有模型中选择相近的，通过 `patches` 字段覆写特定参数，不必从零开始。

## 核心校验逻辑
- 初始 `value` 必须在 `bounds` 范围内。
- `formulas` 中使用到的变量，必须在 `variables` 中声明。
- 若有引用孤立参数，Generator 自动生成 `mods/patch/your_model_patch.yaml` 占位符。
