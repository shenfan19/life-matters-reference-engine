# 胰岛素-血糖生理模拟模型

## 功能描述
本mod实现了一个基于YAML配置的胰岛素-血糖生理调节系统模拟模型。模型模拟以下生理机制：
- 胰岛素对血糖水平的调节作用
- 不同生理/病理条件下的激素响应
- 糖尿病等代谢异常状态的模拟

## mod安装
将 `example_mod_1` 文件夹完整放置到游戏根目录的 `mods/` 目录下即可。

* **兼容游戏版本**：[版本号] 及以上。

## 脚本编写
模型通过YAML文件定义，包含以下核心部分：
```yaml
# 示例结构
variables:
  blood_glucose:
    unit: mmol/L
    normal_range: [3.9, 6.1]
    
rules:
  insulin_response:
    trigger: blood_glucose > 6.1
    action: increase_insulin(20%)
```
